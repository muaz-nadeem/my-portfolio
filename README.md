# Moaz Nadeem — Portfolio

Personal portfolio website showcasing my work as a CS Engineer, Frontend Developer, and AI/ML enthusiast.

## Tech Stack
- Pure HTML5 + CSS3 (no frameworks)
- EmailJS for contact form
- Responsive design with hamburger menu
- Custom animations & smooth scrolling

## Features
- Clean, modern UI with boxed grid theme
- Fully responsive (mobile, tablet, desktop)
- Contact form integrated with EmailJS
- Smooth section navigation
- Custom cursor effects (desktop)
